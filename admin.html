Mở trang tra cứu

1. Nhập file điểm

Chấp nhận file Excel (.xlsx) mỗi môn một sheet, có cột “Họ và tên”, “Ngày sinh”; các cột còn lại là điểm. Cột có tên chứa “Nhận xét” hoặc “Ghi chú” được hiển thị thành lời nhận xét. Cột “STT”, “Mã định danh” được tự động ẩn. Cũng nhận file CSV theo mẫu hoặc file JSON gốc đã xuất từ trang này.

File chỉ được đọc trên máy của bạn, không gửi đi đâu.

2. Kiểm tra dữ liệu

Chưa có dữ liệu. Nhập file ở bước 1.

3. Tạo data.json để đăng

  1. Vào kho GitHub của trang, bấm vào file data.json → biểu tượng bút chì, hoặc “Add file → Upload files”.
  2. Tải lên file data.json vừa tạo để thay file cũ, bấm “Commit changes”.
  3. Đợi 1–2 phút rồi mở trang tra cứu để kiểm tra.

Bản gốc chứa họ tên và điểm ở dạng đọc được. Chỉ lưu trên máy của bạn, tuyệt đối không tải lên GitHub.
